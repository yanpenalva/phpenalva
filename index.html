Quickstart

Install, migrate, serve.

Start a local PHP server and inspect the first JSON response.

Full quickstart →
git clone https://github.com/yanpenalva/phpenalva.git
cd phpenalva
cp .env.example .env
composer install
rm -f database/database.sqlite
php bin/phpenalva migrate
php -S 127.0.0.1:8000 -t public
curl -s http://127.0.0.1:8000/api

Showcase

Web pages and HTTP routes

The application includes a shared page layout and routes for posts and contact. The landing route is /; /posts requires authentication, /post/{id} displays an individual post, and /contact renders the contact page. /debug is available only when APP_DEBUG=true.
